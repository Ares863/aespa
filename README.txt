SITE DE FÃ — GISELLE / aespa

Como abrir:
1. Extraia o arquivo ZIP.
2. Abra a pasta.
3. Dê dois cliques em index.html para visualizar no navegador.

Como trocar a foto:
- Substitua assets/giselle.jpg pela nova foto.
- Mantenha o nome giselle.jpg para não precisar alterar o código.

Player:
- O player incorporado é do Spotify e mostra a página de artista do aespa.
- Ele precisa de internet e pode pedir login.
- O site não inclui arquivos de música protegidos por direitos autorais.

Para publicar:
- Envie a pasta para um serviço de hospedagem estática, como Netlify ou GitHub Pages.
